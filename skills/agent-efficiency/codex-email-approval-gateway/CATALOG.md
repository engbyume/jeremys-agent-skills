# Codex Email Approval Gateway

**Category:** [Agent Efficiency](../README.md)

Sends 5% remaining quota alerts only when an active Codex task observes the threshold, once per reset window, and relays verified same-thread approval replies to the registered task. It does not poll or clear native permission prompts.
