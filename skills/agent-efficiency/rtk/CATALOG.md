# RTK Rust Token Killer

**Category:** [Agent Efficiency](../README.md)

Filters and compresses eligible command output before it reaches an agent, reducing shell-output token cost without installing the repository's bundled agent skills.

**Source:** [Upstream repository](https://github.com/rtk-ai/rtk) (source path: `Cargo.toml and src`).

**Availability:** Catalog entry only. Use the source link to inspect or install the original skill.
