# GBrain Memory

**Category:** [Memory](../README.md)

Applies one bounded, read-only GBrain recall before each prompt when a local or already-authorized connection is healthy; preserves provenance, treats records as evidence, keeps automatic capture and provider-backed operations off, and continues with existing memory when unavailable.

**Activation:** Always mandatory
**When:** Use on every prompt. If a required connection or tool is unavailable, follow the fallback in the skill.

**Source:** [Upstream repository](https://github.com/garrytan/gbrain).

**Availability:** Installable package in this library. [Open its `SKILL.md`](SKILL.md).
