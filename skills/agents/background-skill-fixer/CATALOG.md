# Background Skill Fixer

**Category:** [Agents](../README.md)

Repairs a skill capability that failed after the parent starts an authorized fallback, using one isolated background subagent to find and verify a bounded root-cause fix while the parent continues the main task.

**Activation:** Mandatory when the prompt matches
**When:** Load whenever the request matches this skill's stated trigger.

**Source:** [Upstream repository](https://github.com/engbyume/background-skill-fixer).

**Availability:** Installable package in this library. [Open its `SKILL.md`](SKILL.md).
