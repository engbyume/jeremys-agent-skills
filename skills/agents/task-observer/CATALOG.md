# Task Observer (Codex adaptation)

**Category:** [Agents](../README.md)

Mandatory prompt-start, material-change, and end audits for evidence-backed skill learning and autonomy. It keeps the same goal active through retries and fallback while preserving real user-authority boundaries.

**Activation:** Always mandatory
**When:** Use on every prompt. If a required connection or tool is unavailable, follow the fallback in the skill.

**Source:** [Upstream repository](https://github.com/rebelytics/one-skill-to-rule-them-all) (source path: `SKILL.md`).

**Availability:** Installable package in this library. [Open its `SKILL.md`](SKILL.md).
