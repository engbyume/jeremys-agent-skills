Category index for memory and knowledge skills. Upstream instructions stay with their authors; only this library's packages with a `SKILL.md` can be installed from this repository.

| [Recall](./recall/CATALOG.md) | Retrieves relevant prior context and decisions for the current task. | Catalog only |

| [Remember](./remember/CATALOG.md) | Stores durable facts and decisions for later agent retrieval. | Catalog only |
