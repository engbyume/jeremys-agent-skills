# Cloudflare Security Audit

**Category:** [Security](../README.md)

Multi-phase, source-first security audit guidance. It maps trust boundaries, plans coverage, validates each candidate independently, and produces machine-readable findings and target-neutral reports. Cloudflare says this single-repository skill seeded its larger vulnerability discovery harness.

**Activation:** Mandatory when the prompt matches
**When:** Use at project setup for reconnaissance and after implementation for the full security audit, when an active and fully scanned copy is available.
