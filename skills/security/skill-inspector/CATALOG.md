# Skill Inspector

**Category:** [Security](../README.md)

Mandatory agent-skill intake review using NVIDIA SkillSpector, complete-coverage checks, source-level triage, and removal only when malicious behavior is confirmed.

**Activation:** Mandatory when the prompt matches
**When:** Load whenever the request matches this skill's stated trigger.

**Source:** [Upstream repository](https://github.com/NVIDIA/skillspector) (source path: `skills/skill-inspector`).

**Availability:** Installable package in this library. [Open its `SKILL.md`](SKILL.md).
